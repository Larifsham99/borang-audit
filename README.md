# Borang Audit Pengeluaran

Aplikasi satu fail (`index.html`) untuk menyediakan muka depan dokumen audit pembelanjaan:

- **Halaman 1 – A4 landskap**: tahun, pengeluaran ke-, tarikh, amaun, pembelanjaan, baki dibawa kehadapan, tandatangan.
- **Halaman 2 – A4 potret**: tajuk projek, senarai perkara (dengan pecahan a, b, c…) dan jumlah.

## Cara guna
1. Buka `index.html` dalam Chrome / Edge (komputer atau telefon).
2. Isi borang di sebelah kiri. Pratonton dikemas kini serta-merta.
3. **Cetak** – cetak terus (orientasi setiap halaman ditetapkan automatik). Boleh juga pilih *Simpan sebagai PDF* dalam tetingkap cetak.
4. **Muat turun PDF** – jana fail PDF terus (perlu internet untuk memuat pustaka PDF kali pertama).

Jumlah, pembelanjaan dan baki dikira automatik. Pembelanjaan boleh ditulis sendiri jika berbeza.
Rekod disimpan dalam pelayar; guna **Simpan sandaran (.json)** untuk simpan ke fail / pindah ke komputer lain.
